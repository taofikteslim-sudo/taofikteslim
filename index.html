People Operations

Leave Application Notification Automation

A simple workflow that removes a repetitive notification step from the leave process.

The problem

Leave applications relied on someone remembering to manually notify the employee's line supervisor. This created a simple but repetitive administrative step that was easy to miss.

What I built

A workflow that triggers when a leave application is submitted and automatically sends an email notification to the relevant line supervisor.

Workflow

Leave application
submitted→Workflow
trigger→Details
captured→Supervisor
identified→Email
notification

Tools

No-code workflow automation platform

Human involvement

The automation handles notification. The human decision about leave approval remains with the appropriate person.

What I learned

How to design trigger conditions, route notifications correctly and test a workflow end to end.

02

Recruitment Operations

Recruitment Workflow Automation

A workflow connecting application intake, acknowledgement, CV screening and candidate communication.

The problem

Recruitment involved several repetitive steps, including acknowledging applications, screening CVs and communicating with candidates. These steps were easy to delay or forget when handled manually.

What I built

A recruitment workflow covering application intake, automatic acknowledgement to the applicant, CV screening and candidate communication based on the screening outcome.

Workflow

Application
submitted→Automatic
acknowledgement→CV
screening→Screening
outcome
Pass → candidate communicationDoes not pass → candidate communication

AI involvement

ChatGPT and Claude were used to help think through the screening logic.

Human involvement

Candidate screening involves judgement. The workflow supports the process rather than removing human responsibility from decisions that need context.

What I learned

How to connect multiple steps into one workflow, build decision logic and recognise where human review remains necessary.
