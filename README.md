# Taofik Adenuga Teslim Portfolio

Static GitHub Pages portfolio for People Operations, HR process improvement and workflow automation.

## Publish

1. Create a GitHub repository named `YOUR-USERNAME.github.io`.
2. Upload everything in this folder to the repository root.
3. Go to Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select `main` and `/ (root)`.
6. Save.
7. Visit `https://YOUR-USERNAME.github.io`.

Replace the LinkedIn placeholder when you have your profile URL. Add your real workflow screenshots to the project pages before submitting. Keep screenshots free of real employee or candidate information.
